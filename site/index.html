What happens when an AI improves the way it improves itself?

If one version learns something and the next version inherits it, what happens when the original lesson turns out to be wrong?

Act 4 — The stop

That experiment never started.

It did.

OpenLine RSI renders frozen scientific records. It is a presentation layer: it runs no experiments, modifies no evidence, and is not an authority over any result. The source repositories remain authoritative.
